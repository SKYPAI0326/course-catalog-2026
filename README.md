## 操作

- `← →` 翻頁
- 滾輪 / 觸控滑動
- `ESC` 顯示總覽縮圖
- 第 4 頁 pipeline：按 `→` 或空格逐階點亮
- URL `#N` 可直接跳到指定頁（例如 `/#5`）
- URL 加 `?static` 跳過動效（用於截圖、列印、嵌入 iframe）

## 技術

- 單一 HTML 檔案，無建置流程
- WebGL shader 雙背景（深色：色散；淺色：流動）
- Motion One 動效（CDN）
- Lucide icons / Google Fonts（Noto Serif TC + Playfair + Inter）
- 主題色：🌊 靛蓝瓷
